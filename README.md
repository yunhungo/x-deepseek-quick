# DSQuick

非官方 DeepSeek 网页桌面壳，支持 macOS、Linux 与 Windows。账号、聊天和上传由 DeepSeek 官网处理，应用不调用私有聊天接口。

## 构建和运行

需要 Node.js 20.19+（20.x）或 22.12+，Rust 工具链固定为 1.90.0。macOS 需要 Xcode 命令行工具；Linux 需要 GTK 3、WebKitGTK 4.1 与相应构建工具；Windows 需要 WebView2 和 Rust/MSVC 工具链。

```sh
npm ci
npm run tauri dev
npm test
npm run tauri build -- --bundles app
```

macOS 成果为 `src-tauri/target/release/bundle/macos/DSQuick.app`。其他系统运行 `npm run tauri build`，在 `src-tauri/target/release/bundle/` 获取对应安装包。桌面库仅生成 `rlib`，不生成移动端库。

桌面 App 不注册全局快捷键。macOS 用 Command+Q 退出，Command+W 隐藏窗口；点击 Dock 图标或再次启动会显示已有窗口。

macOS 隐藏原生标题栏与交通灯，顶部空白可拖动；按钮和输入控件优先接收点击。整个窗口采用 20px 圆角，最小尺寸为 420 × 480。窗口大小和位置自动保存。

## 输入法兼容

macOS 通过公开的 `WKWebViewConfiguration.applicationNameForUserAgent` 追加 `DSQuick/<版本> Safari` 兼容标识，保留 WebKit 自动生成的系统和引擎信息，启用官网的已有兼容分支。微信输入法实测会在 `compositionend` 后 13ms 发出 `Enter / keyCode 229 / isComposing=false`，超过官网 10ms 的组词状态保留时间。因此适配器在允许的站点、macOS WebKit 编辑区内，仅阻止 `Enter + 229` 进入网页快捷键处理；不取消原生输入法默认动作，不拦截普通 Enter，不依赖计时器或组词状态。更新时用真实微信输入法检查回车确认英文、空格确认中文、正常回车发送及 Shift+回车换行。

## 磨砂和网站适配

原生窗口负责桌面背景模糊、透明、圆角和快捷键；网站适配器仅负责网页表面。macOS 使用原生 `NSVisualEffectView` 模糊窗口背后的画面，网页根背景仅叠加一次随官网主题变化的中性蒙层（浅色白色 42%，深色黑色 68%），避免反差很大的桌面背景吞没文字；保留原生高斯模糊。`src-tauri/src/macos_glass.rs` 只在自身材质层中识别到背景模糊后，清除额外染色与饱和度增强；层级或滤镜无法识别时保留系统材质。内部图层不是公开稳定合同，系统升级后可能退回带调色的毛玻璃。不会修改 WebKit 图层，也不硬链接非公开窗口接口。输入框、代码卡片及页脚仍保留阅读所需的表面与阴影。Windows 使用 Mica/Acrylic，Linux 由桌面合成器提供模糊。GNOME 等没有窗口背景模糊能力的合成器只能显示透明效果。

适配代码集中在 `src-tauri/scripts/glass.js`：

- `POLICY` 维护版本、扫描上限、语义保护范围和交互范围，不依赖官网散列类名。
- `classifySurface` 是纯分类函数，仅允许识别出的浅层布局背景和页头/页脚表面；尺寸本身不构成修改依据。
- 消息、代码、输入、圆角卡片、对话框和抽屉保留官网表面。代码卡片从外层裁剪，避免下方露出直角背景。
- 输入框外围按位置、尺寸识别空渐变装饰（普通元素或伪元素），清除外围渐变和模糊涂层，保留圆角输入卡片本身的背景与阴影；识别范围随视口及输入框高度变化，不依赖散列类名，不删除节点或改变点击与布局。底部输入区容器保持透明，避免与全窗口主题蒙层叠加成矩形深色块；窗口原生模糊继续保留。
- 未知结构或颜色保留官网样式；异常时撤销本轮表面标记，不强行透明化。
- 滚轮和触控板事件不拦截、不自行插值；滚动及惯性阶段延后布局适配，静止 160ms 后再合并刷新。只关注已识别布局节点的属性变化，避免消息控件状态触发整轮扫描。macOS 14+ 显式关闭 WebView 后台任务节流，隐藏时仍可继续处理网页任务。
- 扫描有深度、节点数与时间合并限制；不遍历整段聊天内容。自身标记不会反复触发观察器，页面离开时清理监听与定时器，并兼容浏览器往返缓存。

脚本作为 `scripts/glass.js` 应用资源分发，正式版启动时读取随包副本；开发模式读取项目源文件。只改网页适配时，在已有原生构建后执行：

```sh
npm run test:adapter
npm run tauri bundle -- --bundles app
```

重新打包会使用当前脚本，无需重新链接原生程序。修改 Rust、依赖、权限或窗口配置后仍需完整构建。不要直接修改已签名应用包里的资源。

官网 DOM 并非公开接口，不能保证未来任意版本自动兼容。更新适配器时先跑契约测试，再实看宽/窄窗口、长短用户消息、代码卡片、输入框、侧栏、对话框和深浅主题；未知布局优先保留可用性。

## 本机配置与登录状态

首次启动从 `src-tauri/launcher.json` 创建本机配置。macOS 位于 `~/Library/Application Support/app.deepseekglass.launcher/launcher.json`；Linux 位于 `~/.config/app.deepseekglass.launcher/launcher.json`；Windows 位于对应应用配置目录。也可用 `DEEPSEEK_GLASS_CONFIG` 指定本机配置文件，修改后重启。

配置支持 `chatUrl`（HTTPS）、`allowedHosts` 和 `glass.enabled`。仅允许主机上运行适配脚本。旧版透明度和覆盖阈值字段仍可读取以兼容旧文件，但保守适配器不再用这些值识别消息或逐层叠加底色。

WebView 明确关闭无痕模式，使用系统持久化网站数据存储。Cookie、Local Storage 与登录状态由 WebKit/WebView 在本机管理，不导出到源码或配置。保留原应用标识 `app.deepseekglass.launcher`，改名不会主动隔离原有登录数据；会话期限、退出登录和远端撤销仍由 DeepSeek 控制。窗口状态与本机配置、网站数据都不应进入 Git。

远程网页仅获主窗口拖动权限，无文件系统或 shell 权限；只允许主窗口的 DeepSeek 官网调用拖动。登录弹窗允许在 WebView 内完成。网页没有本机文件访问能力，文件拖放交给官网上传控件。

## 图标

正式源图为 `src-tauri/icons/source.png`，是按用户参考生成的蓝发 Q 版头像，不代表 DeepSeek 官方应用。运行 `python3 -B scripts/render-icon.py` 根据源图重新生成平台图标；仅保留当前目标需要的正式资源，清理未使用的生成目录。

`.myself/` 用于被忽略的本机任务文件；不提交临时截图、测试报告、凭据或构建包。正式应用与可复用构建缓存保留在现有工具输出目录。

## macOS 正式安装包

完成原生 release 构建后运行 `npm run package:mac`：先打包当前网页资源，再补全 APP 签名、生成包含应用与 Applications 入口的 DMG，并只读挂载验证签名和适配器内容。默认使用本机 ad-hoc 签名；如配置 `APPLE_SIGNING_IDENTITY` 则沿用该身份。此流程不代表完成 Apple 公证。临时安装目录与挂载自动清理，正式 APP 和 DMG 留在既有 bundle 输出目录。

## Chrome 扩展（预览版）

```sh
npm ci
npm run build:extension
```

在 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，加载 `extension/dist`。图标与网页适配器来自桌面应用的现有资源；扩展构建不修改桌面 APP 或其登录数据。

Command+Shift+D（Windows/Linux 为 Ctrl+Shift+D）按已保存模式打开当前 Tab 的网页内悬浮层或固定侧栏，不创建独立窗口。默认悬浮并贴齐网页可视区左侧、顶部和底部，宽度 460px，窄窗口自动缩小；标题栏空白处可拖动，右下角可缩放，双击标题栏空白处恢复默认尺寸和位置；模式、外观和悬浮位置尺寸在本机保存。悬浮模式在点击外部或切走焦点后以 240ms 过渡将内容降至 1.5% 不透明度，背景与阴影完全淡出，边框保持较高可见度，鼠标移回或重新唤起时恢复；外部滚动不改变透明度，固定侧栏不参与淡出，并尊重系统减少动态效果设置。扩展图标弹出设置与采集入口，固定侧栏不显示自定义顶部工具栏。快捷键冲突可在 `chrome://extensions/shortcuts` 调整。浏览器内部页等无法注入的页面不采集。每个来源 Tab 使用独立面板页面与对话，关闭来源 Tab 会清理对应路由记录；来源页面导航不自动采集，选择状态在 pagehide 清理。同一 Tab 通过官网路由恢复当前对话，不复制聊天正文。

工具栏的选取按钮进入实时 hover 高亮，点击采集当前元素及其子内容，Esc 取消；整页按钮优先读取 main/article 正文，再回退 body。提取标题、链接、列表、表格行、代码、可访问名称及图片描述，跳过隐藏节点、输入控件、可编辑区域和脚本。开放 Shadow DOM 可读取，跨域 iframe、封闭 Shadow DOM 与未加载的虚拟列表会缺失；这是 DOM 语义提取，不冒充浏览器原生 AX 全树，也未使用 ChatGPT 私有实现。提取限制 12,000 节点、60 层及约 180,000 字符，并在截断时标注。

文本用 UUID 文件名的 TXT 交给 DeepSeek 官网原生文件输入控件；选中单独图片时上传当前可见区域的 PNG（不是原图下载）。整页内图片目前以描述和链接包含在 TXT 中。不会自动发送消息，上传是否完成以官网附件状态为准。官网控件无法识别时提示并保留内存中的待传内容，重新点击采集可重试；关闭面板或刷新后不持久保存网页附件。

对话页面实例按来源 Tab 分离。悬浮 iframe 的官网登录存储可能被来源站点分区，登录共享通过下述受限会话适配完成；不读取、导出或复制 Cookie，也不与桌面 WebKit 会话同步。验证码及官网限制仍可能要求重新登录。

为显示嵌入官网，扩展对本扩展发起的 `chat.deepseek.com` 子框架文档移除 CSP 与 X-Frame-Options 响应头；官网自己发起的登录跳转与刷新则限定在已打开面板的 Tab 和无关联 Tab 的侧栏上下文中。规则仅匹配官网 HTTPS 子框架，不匹配主文档或其他目标站点。规则安装串行且幂等，面板导航前等待安装完成，来源 Tab 关闭时清理对应范围。此范围内的网站 CSP 保护因此不再完整，正式上架前需再次审核；扩展自身保持严格 CSP，不执行远程扩展代码。只申请当前标签的 activeTab 读取权限和 DeepSeek 主机权限，不申请浏览历史、Cookie 或全站持久访问权限。整页提取不申请 debugger 权限，也不建立调试连接。

悬浮外层通过 CSS `backdrop-filter: blur(28px)` 模糊后方网页，固定侧栏采用浏览器背景；不能产生桌面高斯模糊；网页嵌入层的跨框架合成与原生 macOS 背景模糊不同，不保证能透过官网页面看到后方网页。工具栏外观下拉菜单列出跟随系统、浅色、深色并勾选当前项，官网主题由官网设置管理。当前仍需 Chrome 内实测登录、侧栏、文件上传及不同站点，不能仅据构建通过视为正式可用版本。

### 悬浮面板登录共享

网页内悬浮的 DeepSeek Local Storage 经跨 Tab 顺序检测确认会被来源站点隔离。用户启用的登录共享仅适配官网 `userToken` 存储项：已登录的官网标签或获准的扩展面板可提供登录数据，扩展仅通过 `chrome.storage.session` 在本次浏览器会话内存中暂存，向同源 DeepSeek 面板补齐缺失项。既有不同登录数据保留，聊天、草稿、附件和其他存储项均不转移。不输出凭据到日志、诊断或扩展设置，不使用 `chrome.storage.local` 保存凭据，也不发给来源网页。退出或失效清除相应会话缓存；没有有效共享凭据时仍需正常登录。

补齐登录后只刷新官网 iframe，不刷新来源网页；非空编辑草稿优先保留，且按会话版本设置补齐标记，防止失效凭据造成循环刷新。官网更改存储键或结构时会停止共享，不自动扩大读取范围。该登录适配仍须在实际 Chrome 登录会话内验证，自动检查不替代真实跨站验收。

### 扩展快捷键

`chrome://extensions/shortcuts` 中可配置三个命令：

- **唤起 DSQuick**：macOS 建议 Command+Shift+D，其他平台建议 Ctrl+Shift+D；悬浮时切换显示/隐藏，固定时打开当前 Tab 的侧栏。
- **局部选择网页元素并添加附件**：进入 hover 高亮选择，点击采集，Esc 取消。
- **提取整页内容并添加文本附件**：提取网页正文，生成 UUID 命名的 TXT，不是截图。

后两个命令默认不分配组合键，避免占用浏览器或其他扩展的快捷键。Chrome 可能因已有冲突而不注册建议的唤起组合键，页面显示「未设置」时可手动指定。Chrome 自带的「激活该扩展程序」打开设置弹出页，与唤起面板是不同入口。快捷键与弹出页共用面板唤起和采集队列，首次未打开面板时也会先唤起再采集，不自动发送消息。

### 网页上下文提取

用户已有正文选区时，“选择元素”和“添加整页”优先将选中文字原样作为 TXT 内容，不添加整页文字或元信息。输入控件与可编辑草稿中的选区不读取。无选区时，选择元素使用本地高亮；整页通过 DOM 语义结构提取当前已加载的正文、标题、链接、列表、表格和代码。此路径不连接 Chrome 调试器，因此不会因提取而触发浏览器调试提示。

提取仅在用户触发后运行，不读取输入值或可编辑草稿，不执行远程扩展代码，不调用私有接口。当前覆盖主文档已加载的 DOM 内容，不保证读取跨域框架、尚未加载的虚拟内容、Canvas 或图片中文字。

参考：OpenAI 的公开浏览器扩展文档说明网页、选区及截图能力，但没有公开内部提取算法，因此该实现仅对齐公开能力方向，不声称等同其内部实现。


### 默认悬浮布局与官网提醒

默认高度跟随实际可视区域，浏览器窗口或可视区变化时继续贴齐底部。只有拖动或操作缩放角才保存为自定义尺寸；旧版未标记的矩形记录会迁移为新默认布局。双击标题栏空白处可随时恢复默认。

内嵌官网的“请检查浏览器插件”卡片，在用户主动点击一次“知道了”后记录确认状态，后续面板遇到相同提醒会复用确认。仅存储一个布尔偏好，不记录提醒或聊天内容。匹配范围限定为这一明确提醒，正常官网登录页与其他错误提示保持官网行为；如果实际请求仍被其他扩展拦截，需要按具体网络失败排查。
